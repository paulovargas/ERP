# ERP Web App

Frontend do ERP feito com Angular 22.3.0, Angular Material 22.3.0 e Bootstrap 5.

## Requisitos

- Node.js 24.15.0 (`.nvmrc`)
- npm 11 ou superior

## Instalar e iniciar

```bash
nvm install 24.15.0
nvm use 24.15.0
npm ci
npm start
```

A aplicacao fica disponivel em `http://localhost:4200`.

## Build

```bash
npm run build
```

Para gerar os arquivos usados no GitHub Pages:

```bash
npm run build:github-pages
```

## Testes existentes

```bash
npm test
```
